# bonkey-math

Public GitHub Pages host for the **Bonkey Math** free web demo and landing site.

This repository's contents are published automatically. The landing site (repo
root) and the free-tier web app (under `app/`) are synced here by the
`pages-deploy` workflow in
[`Bonkey-Apps/bonkey-math-app`](https://github.com/Bonkey-Apps/bonkey-math-app),
which builds the Expo web export, opens a PR here, and auto-merges it to publish.

Do not edit the published files by hand — they are overwritten on each deploy.
